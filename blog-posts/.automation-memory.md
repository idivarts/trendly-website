# Daily Blog Automation — Memory & Context

> Persistent context for the `daily-trendly-blog` scheduled task. Read this at the
> start of every run. Update the "Run log" section at the bottom after each run.

## Objective
Every day, write ONE new blog post for the Trendly marketing website, build/deploy
it, and commit+push to the current git branch.

## Positioning (MUST follow — see trendly-website/CLAUDE.md for full detail)
- Trendly = **the AI social media tool for founders & small teams** — every AI
  model (GPT, Claude, Gemini, etc.) in one workspace. Create → collaborate →
  schedule → engage. "More than a scheduler."
- Audience is **global** (solo founders, small in-house teams, agencies). USD
  pricing. Do NOT reintroduce the old India-D2C-marketplace / "Pilot Programme" /
  INR / sub-100k-micro-creator framing.
- 🛑 **Honesty rule:** NEVER fabricate testimonials, logos, ratings, user counts,
  ROI numbers, or "trusted by X" claims. Only approved proof: 10,000+ creators
  joined the network, team behind 100s of brand campaigns, first-100-founders
  offer, "free forever / no card / cancel anytime". Keep new posts idea/education
  led — no invented stats.

## Where topics come from
Notion "Blog Ideas" database (data source id `39342d5f-1701-804a-87fd-000b9230f89a`,
URL https://www.notion.so/39342d5f170180cbb592d8c57b8d2501). Use the
`notion-query-data-sources` / `notion-fetch` tool to read the list of topic ideas.
These are TOPICS, not fixed titles — craft a fresh title from a topic.

## How to know what's already been written
The `trendly-website/blog-posts/` folder is the source of truth. List the `*.md`
files and read their `title:`/`slug:` frontmatter. Pick a topic NOT already
covered. Never duplicate an existing slug/title/topic.

## File naming
Files are numbered sequentially: `NN-kebab-title.md`. Find the highest existing
prefix and use the next number (e.g. after `13-…` create `14-…`).

## Required frontmatter (copy this template exactly — key `title`, NOT `drtitle`)
```
---
title: "Your Title Here"
slug: your-kebab-case-slug
date: 05 Jul 2026
dateISO: "2026-07-05"
author: Trendly Team
cat: Strategy
readTime: 6 min read
excerpt: "One-sentence hook shown on the blog card."
metaDescription: "SEO meta description ~150 chars."
targetKeyword: primary seo keyword phrase
gradient: from-violet-500 via-purple-500 to-sky-400
imageUrl: https://images.unsplash.com/photo-XXXX?w=1200&h=750&fit=crop&auto=format&q=80
---

# Your Title Here

...body in markdown (H2 `##` section headings, short paragraphs)...
```
- `cat` should be one of: Strategy, How To, Insights, Platform, Blog.
- Use the ACTUAL current date for `date` / `dateISO` (run `date` in bash).
- Body ~800–1200 words, useful and specific, aligned to positioning above.
- Vary the `gradient` and `imageUrl` (pick a relevant Unsplash photo id) so cards
  don't all look identical.

## Build + deploy + push
From `trendly-website/`:
1. `npm run build`  ← this runs `./export.sh && ./deploy-s3.sh` (build AND deploy).
2. `git add blog-posts/<new-file>.md` (and the `.automation-memory.md` log update)
3. `git commit -m "blog: <title>"`
4. `git push` (current branch — already configured; do NOT switch branches)
